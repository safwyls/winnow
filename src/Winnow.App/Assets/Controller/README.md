# Controller prompts

These 16 unmodified SVGs are the Xbox Series subset of **Kenney Input Prompts 1.5A**,
distributed under **CC0 1.0**. The original archive's license is in `License.txt`.

- [Source and download](https://kenney.nl/assets/input-prompts)
- [Kenney's prompt guidance](https://kenney.nl/knowledge-base/game-assets-2d/using-input-prompts)
- [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

Downloaded on 2026-09-09 from the official `kenney_input-prompts_1.5.zip` archive.
Credit: Kenney (www.kenney.nl).

`FullscreenGlyphs` reads the bundled path geometry and applies the current theme's Text
brush. It preserves each silhouette's aspect ratio and removes the source canvas padding.
The selected files contain untransformed paths with a white fill and no strokes; this
limited loader does not add a general SVG dependency. Xbox labels match Winnow's current
input mapping; the app does not detect or claim a device-specific glyph family.

The Winnow mark uses the existing `Assets/Icons/dragon.svg`, not this third-party set.
