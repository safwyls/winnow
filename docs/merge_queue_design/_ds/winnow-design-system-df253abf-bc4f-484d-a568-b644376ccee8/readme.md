# Prototype design assets

This is the frozen CSS and font bundle used by the [merge queue prototype](../../README.md).
It is not an app design system or an agent instruction source. The current visual specification
is [design-system.md](../../../../design-system.md), with resources in the app's `tokens.axaml`.

| Path | Contents |
|---|---|
| `styles.css` | Entry stylesheet |
| `tokens/` | Prototype colours, type, spacing, geometry and motion |
| `assets/fonts/` | Bundled fonts used by the prototype |
| `_ds_bundle.js`, `_ds_manifest.json` | Export runtime and manifest |
| `_adherence.oxlintrc.json` | Export tooling configuration |

Keep the bundle with its prototype. Its values and labels describe that artifact only.
