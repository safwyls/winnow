Everything in the proposed tree is reachable with four attached properties that Avalonia 11.3.20 actually wires to Windows UIA: ControlTypeOverride, HeadingLevel, AccessibilityView and LiveSetting. Three traps found by checking the 11.3.20 source rather than assuming, each of which would have produced code that compiles and does nothing: AutomationProperties.Name on a TextBlock is silently ignored; PositionInSet and SizeOfSet compile but are wired to nothing, so a count has to be spelled into the name string; and changing a Name at runtime raises no UIA event, so a live region must be a TextBlock whose Text is bound.

Not drawn here, deliberately. Price paid is absent from every state. The IGDB match and metadata editor sections are unchanged and are not redrawn. Focus rings, hover states and the dormancy ramp on cover art are not simulated because this pass does not change them.
