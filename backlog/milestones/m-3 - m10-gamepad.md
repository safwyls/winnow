## Description

Full-screen mode with gamepad navigation. The entire app is navigable on a controller at 10 feet. This is a second complete UI surface: focus management, controller input, its own navigation model and layouts. Deliberately last; serves the narrowest user segment.

Exit criteria: every screen and interaction is reachable via gamepad; focus is always visible; no mouse or keyboard required.
